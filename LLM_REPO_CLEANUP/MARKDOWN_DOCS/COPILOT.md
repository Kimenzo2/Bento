# Genesis — Copilot Design Context

## Design Context

### Users
Parents, educators, and young creators (ages 8–35) who want to craft beautiful, AI-assisted children's stories, infographics, and visual books. They use the app in creative bursts — often on tablet or desktop, expecting the interface to feel as warm and imaginative as the content they create.

### Brand Personality
**Warm. Imaginative. Playful.**

- Voice: encouraging, delightful, never technical
- Tone: like a friendly creative studio, not a SaaS dashboard
- Emotional goal: make users feel like gifted storytellers the moment they open the app

### Aesthetic Direction
- **Visual tone**: Cozy editorial — warm cream backgrounds, coral/gold accents, flat design (no shadows)
- **Fonts**: Fredoka (headings) + Manrope (body) — round, friendly, readable
- **Color language**: Warm spectrum — coral-burst (#FF9B71), gold-sunshine (#FFD93D), cream-base (#FFF8E7), peach-soft (#FFE4CC), charcoal-soft (#5A5A5A)
- **References**: Notion (calm density), Canva (accessible delight), Duolingo (emotion + progress)
- **Anti-references**: Generic SaaS (cold blues, gray neutrals), heavy dashboards, nested card UI

### Design Principles
1. **Warmth first** — Every surface should feel inviting, never clinical
2. **Pixels feel light** — Flat design, no heavy shadows, let colors breathe
3. **Semantic tokens only** — Never hard-code color values; always use CSS variables / Tailwind token aliases
4. **Delight without distraction** — Motion and micro-interactions should feel purposeful, never bouncy or aggressive
5. **Mobile-first, thumb-friendly** — All interactive targets ≥ 44px; spacing generous on small screens
