# @gen-engine/bridge

Public SDK for integrating Gen AI companion into Genesis.
Composes renderer, brain, and voice into a single interface.

## Status
Active development. Canvas 2D placeholder renderer.
WebGPU rendering pending commissioned GLTF character model.

## Install
```bash
npm install @gen-engine/bridge
```

## API
```typescript
import { preload, mount, unmount, publish, trigger } from '@gen-engine/bridge'
```
